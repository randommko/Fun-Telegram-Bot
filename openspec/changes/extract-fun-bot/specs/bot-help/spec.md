# Spec Delta

## Purpose

Определяет, какие команды показывает Fun-бот в помощи и как он ведёт себя с командами и сообщениями, которые ему не принадлежат.

## ADDED Requirements

### Requirement: Помощь перечисляет только команды Fun

Система SHALL по команде `/bot_info` показывать список только своих команд: `/cocksize`, `/pidor_start`, `/pidor_reg`, `/pidor_stats`, `/horoscope_today`. Команд AI-бота и админки в списке MUST NOT быть.

#### Scenario: Список команд

- **WHEN** пользователь отправляет `/bot_info`
- **THEN** бот присылает список из пяти команд Fun с кратким описанием каждой

#### Scenario: Чужих команд нет

- **WHEN** пользователь читает помощь
- **THEN** в ней нет `/ai`, `/clear`, `/summary` и других команд AI-бота

### Requirement: Чужие команды игнорируются

Система SHALL NOT выполнять команды, которых нет среди команд Fun, и MUST NOT обращаться к модели или базе AI при получении такой команды.

#### Scenario: Команда AI-бота

- **WHEN** в чат с Fun-ботом приходит `/ai вопрос`
- **THEN** Fun-бот не отвечает и не вызывает модель

#### Scenario: Неизвестная команда

- **WHEN** приходит команда, которой нет в списке Fun
- **THEN** бот записывает её в лог отладочного уровня и не отвечает

### Requirement: Сообщения без команды не обрабатываются

Система SHALL реагировать только на слэш-команды и кнопки и MUST NOT отвечать на обычные текстовые сообщения в чате.

#### Scenario: Обычное сообщение

- **WHEN** в группе приходит сообщение без слэша
- **THEN** Fun-бот не отвечает и не меняет игровые данные

#### Scenario: Ответ на сообщение бота

- **WHEN** пользователь отвечает реплаем на сообщение Fun-бота без команды
- **THEN** бот не воспринимает это как вопрос и не отвечает
