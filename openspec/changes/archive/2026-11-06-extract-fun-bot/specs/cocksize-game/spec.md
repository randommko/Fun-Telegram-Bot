# Spec Delta

## Purpose

Определяет игру «замер достоинства»: ежедневный случайный размер, картинка и подпись по диапазону, а также статистика замеров по кнопке.

## ADDED Requirements

### Requirement: Замер выполняется один раз в сутки

Система SHALL по команде `/cocksize` возвращать сегодняшний замер пользователя, а если его нет — создавать новый и сохранять его с текущей датой. Повторная команда в тот же день MUST возвращать тот же размер.

#### Scenario: Первый замер за день

- **WHEN** пользователь впервые за день отправляет `/cocksize`
- **THEN** бот выбирает размер, сохраняет его в `fun.cocksize_stats` и присылает результат

#### Scenario: Повторный замер за день

- **WHEN** пользователь повторно отправляет `/cocksize` в тот же день
- **THEN** бот присылает тот же размер без новой записи в статистике

#### Scenario: Новый день

- **WHEN** пользователь отправляет `/cocksize` на следующий день
- **THEN** создаётся новый замер, а прежние записи сохраняются

### Requirement: Размер выбирается из набора значений

Система SHALL выбирать размер случайно из набора от 0 до 49 с повторами, чтобы частые значения встречались чаще редких. Последние три замера пользователя MUST NOT исключаться из набора.

#### Scenario: Размер в допустимом диапазоне

- **WHEN** бот выбирает размер
- **THEN** значение попадает в диапазон от 0 до 49

#### Scenario: Недавний размер может повториться

- **WHEN** у пользователя были замеры за последние три дня
- **THEN** эти размеры остаются в наборе и могут выпасть снова

### Requirement: Результат приходит с картинкой и подписью

Система SHALL присылать картинку, выбранную по размеру из справочника `fun.cocksize_imgs`, с подписью, зависящей от диапазона размера. Если картинку не удалось отправить, MUST прислать хотя бы текстовую подпись.

#### Scenario: Картинка найдена

- **WHEN** для размера есть используемая картинка
- **THEN** бот отправляет фото с подписью

#### Scenario: Картинку отправить не удалось

- **WHEN** Telegram отклонил отправку фото или файл недоступен
- **THEN** бот отправляет текстовую подпись без картинки

#### Scenario: Разные диапазоны

- **WHEN** выпали размеры из разных диапазонов
- **THEN** подписи различаются и соответствуют диапазону размера

### Requirement: Кнопка показывает статистику замеров

Система SHALL добавлять к результату кнопку статистики и по нажатию показывать число замеров, даты первого и последнего замера и средний размер с двумя знаками после запятой. Если замеров нет, MUST сообщить, что пользователь ещё не измерялся.

#### Scenario: Замеры есть

- **WHEN** пользователь нажимает кнопку статистики
- **THEN** бот присылает число замеров, период и средний размер

#### Scenario: Замеров нет

- **WHEN** кнопку нажал пользователь без замеров
- **THEN** бот сообщает, что измерений ещё не было

#### Scenario: Кнопка нажимается повторно

- **WHEN** пользователь нажимает кнопку статистики несколько раз
- **THEN** каждый раз приходит актуальная статистика, и замер при этом не создаётся
